# Changelog

## [0.1.0] - 2026-11-02

First version.

* **Files** page in the Cockpit menu ("Bestanden" in Dutch).
* Sidebar with shortcuts (Root, `/DATA` and its well-known folders) and a
  **Location** list of mounted file systems; own entries can be added and
  removed.
* Breadcrumb, grid and list views, selection with select-all.
* New folder, upload, download, rename, move and delete, with confirmation
  before deleting and before replacing files.
* Runs as the logged-in user; administrative access only on an explicit
  retry. No backend of its own.
* Dutch translation.
